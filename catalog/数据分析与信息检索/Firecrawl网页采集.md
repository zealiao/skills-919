# Firecrawl 网页采集（firecrawl）

- **分类**：数据分析与信息检索
- **简要用途**：将公开网页内容转换为适合检索、分析或知识库处理的结构化数据。
- **核心功能**：
  - 抓取、解析和提取网页正文及页面结构。
  - 为后续研究、RAG 或网站资料整理提供入口。
- **适用场景**：公开资料研究、网站内容归档、知识库构建和网页信息抽取。
- **来源平台**：Skills.sh
- **来源链接**：https://www.skills.sh/firecrawl/cli/firecrawl
- **原作者 / 原始仓库**：Firecrawl / firecrawl/cli
- **原始链接**：https://github.com/firecrawl/cli
- **热度 / 评价快照**：Skills.sh 全站榜在 2026-07-31 显示约 95.1K 次安装。
- **采集日期**：2026-07-31
- **安装方式**：`npx skills add https://github.com/firecrawl/cli --skill firecrawl`
- **许可证**：许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验详情页、原始仓库入口与安装方式；未对受限站点执行采集。
- **风险 / 依赖备注**：必须遵守 robots、站点条款、版权和速率限制；不得采集登录后、付费或含个人数据的内容。
