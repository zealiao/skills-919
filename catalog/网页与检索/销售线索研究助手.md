# 销售线索研究助手

- **分类**：网页与检索
- **简要用途**：从公开资料中研究潜在客户、公司背景和联系人线索，辅助制定联系策略。
- **核心功能**：
  - 规划关键词和来源优先级。
  - 对比多个公开来源并标记冲突信息。
  - 生成带链接、日期和待验证项的研究笔记。
- **适用场景**：B2B 销售拓客、客户背景研究、线索优先级排序和联系准备。
- **来源平台**：SkillHub 中国（lead-research-assistant）

- **原作者 / 原始仓库**：来源页 “Source” 标注的原作者待复核
- **原始链接**：https://www.skill-cn.com/skill/13
- **热度 / 评价快照**：通过平台搜索、推荐和标签入口筛选；未作为实时排名记录。
- **采集日期**：2026-07-31
- **安装方式**：在 SkillHub 搜索“网页研究/信息检索”，按详情页的浏览或搜索配置执行。
- **许可证**：未核验；不复制原始文件。
- **人工核验**：已核验平台入口；仅限公开、无需登录的资料研究。
- **风险 / 依赖备注**：必须遵守网站条款、robots 规则和版权限制；摘要需要保留来源，不能替代原文或专家意见。

## 收录说明

研究助手的价值是让来源和推理更可追溯。对于价格、法规、人物和新闻等易变信息，应在使用当日重新核验。
