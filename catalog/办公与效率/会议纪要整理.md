# 会议纪要整理

- **分类**：办公与效率
- **简要用途**：把会议录音、逐字稿或笔记压缩成结构化纪要，突出结论、待办和负责人。
- **核心功能**：
  - 按议题归纳讨论结论和分歧。
  - 提取行动项、负责人和截止日期。
  - 生成适合群聊或文档发布的纪要格式。
- **适用场景**：例会复盘、客户访谈、项目评审和跨部门同步。
- **来源平台**：腾讯 SkillHub

- **原作者 / 原始仓库**：SkillHub 公开收录作者待复核
- **原始链接**：https://skillhub.cn/
- **热度 / 评价快照**：从平台“精选推荐/下载热榜”入口筛选；具体数值待在详情页二次记录。
- **采集日期**：2026-07-31
- **安装方式**：在 SkillHub 搜索“会议纪要”并按详情页安装；需要提供合法取得的会议材料。
- **许可证**：未核验；不复制原始文件。
