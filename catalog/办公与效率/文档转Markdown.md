# 文档转 Markdown

- **分类**：办公与效率
- **简要用途**：将常见办公文档转为便于检索、版本管理和二次编辑的 Markdown 文本。
- **核心功能**：
  - 识别标题、段落、列表和表格等结构。
  - 输出可直接纳入知识库或 Git 仓库的 Markdown。
  - 标记图片、复杂排版和无法可靠转换的内容。
- **适用场景**：知识库迁移、文档归档、项目说明维护和内容再加工。
- **来源平台**：腾讯 SkillHub
- **来源链接**：https://skillhub.cn/
- **原作者 / 原始仓库**：SkillHub 公开收录作者待复核
- **原始链接**：https://skillhub.cn/
- **热度 / 评价快照**：从平台“榜单与标签筛选”入口筛选；未将热度视为实时数据。
- **采集日期**：2026-07-31
- **安装方式**：在 SkillHub 搜索“Markdown/文档转换”，按详情页要求安装依赖。
- **许可证**：未核验；不复制原始文件。
- **人工核验**：已核验平台入口；转换质量待以样本文档抽测。
- **风险 / 依赖备注**：扫描件通常依赖 OCR；转换前应删除不需要共享的附件和修订记录。

## 收录说明

该能力有助于把分散资料纳入可追踪的文本工作流。表格、批注和复杂版式应保留原文件作为事实来源，不能仅依赖转换结果。
