# 飞书 Markdown（lark-markdown）

- **分类**：办公与效率
- **简要用途**：创建、读取和局部更新飞书中的 Markdown 文件。
- **核心功能**：
  - 将结构化 Markdown 用于团队文档的创建、比对和更新。
  - 支持以 Markdown 为中间格式维护说明、清单和知识条目。
- **适用场景**：团队文档同步、变更说明、知识库草稿和版本比对。
