# 仓库健康检查

- **分类**：开发辅助
- **简要用途**：检查项目结构、依赖、测试、文档和常见维护风险，并形成整改清单。
- **核心功能**：
  - 识别缺失的 README、许可证、忽略规则和测试入口。
  - 汇总过期依赖、重复配置和潜在密钥泄露点。
  - 输出按优先级排序的维护建议。
- **适用场景**：接手旧项目、开源前准备、技术债盘点和新成员入门。
- **来源平台**：SkillHub 中国
- **来源链接**：https://www.skill-cn.com/
- **原作者 / 原始仓库**：平台关联作者待复核
- **原始链接**：https://www.skill-cn.com/
- **热度 / 评价快照**：从平台开发实践与 Skill 索引中筛选；具体数据待详情页复核。
- **采集日期**：2026-07-31
- **安装方式**：在 SkillHub 中国按“仓库/工程化/代码质量”关键词定位对应条目。
- **许可证**：未核验；不复制原始文件。
- **人工核验**：已核验平台入口；未运行可能修改项目的修复命令。
- **风险 / 依赖备注**：检查报告可能列出内部路径或依赖漏洞；应在私有环境生成并按需要脱敏。

## 收录说明

健康检查很适合作为新仓库的第一步。报告应区分事实、推测和建议，且不要自动升级依赖或删除文件。
