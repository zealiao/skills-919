# API 文档助手

- **分类**：开发辅助
- **简要用途**：从接口定义、代码和示例中整理面向调用方的 API 文档。
- **核心功能**：
  - 提取端点、参数、响应和错误处理规则。
  - 生成示例请求、返回示例和变更说明。
  - 检查文档与接口实现的明显不一致。
- **适用场景**：内部服务交接、SDK 使用说明、版本发布和接口评审。
- **来源平台**：SkillHub 中国（mcp-builder）
- **来源链接**：https://www.skill-cn.com/skill/41
- **原作者 / 原始仓库**：来源页 “Source” 标注的原作者待复核
- **原始链接**：https://www.skill-cn.com/skill/41
- **热度 / 评价快照**：从平台开发类标签和推荐入口筛选；未记录为实时排名。
- **采集日期**：2026-07-31
- **安装方式**：在 SkillHub 搜索“API 文档”，按具体条目要求连接 OpenAPI 文件或代码仓库。
- **许可证**：未核验；不复制原始文件。
- **人工核验**：已核验平台入口；未对私有接口上传或发布文档。
- **风险 / 依赖备注**：接口文档可能暴露内部地址或鉴权模型，发布前应做脱敏和访问控制审查。

## 收录说明

这类工具适合减少文档滞后，但无法自行保证接口语义正确。建议在 CI 或发布流程中用真实接口定义和人工评审共同校验。
