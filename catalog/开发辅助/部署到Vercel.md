# 部署到 Vercel（deploy-to-vercel）

- **分类**：开发辅助
- **简要用途**：协助将 Web 项目按正确配置部署到 Vercel。
- **核心功能**：
  - 检查部署配置、环境变量和常见框架要求。
  - 指导预览、构建问题排查和发布前验证。
- **适用场景**：Next.js 网站上线、预览环境发布和部署配置检查。
- **来源平台**：Skills.sh
- **来源链接**：https://www.skills.sh/vercel-labs/agent-skills/deploy-to-vercel
