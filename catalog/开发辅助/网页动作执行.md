# 网页动作执行（browser-act）

- **分类**：开发辅助
- **简要用途**：让开发 Agent 在浏览器中按任务执行受控页面动作并获取结果。
- **核心功能**：
  - 组织网页导航、点击、输入、读取和结果检查步骤。
  - 为需要真实浏览器交互的调试和集成验证提供入口。
- **适用场景**：Web 应用调试、内部系统流程演练和开发环境交互验证。
- **来源平台**：Skills.sh
- **来源链接**：https://www.skills.sh/browser-act/skills/browser-act
- **原作者 / 原始仓库**：Browser Act / browser-act/skills
- **原始链接**：https://github.com/browser-act/skills
- **热度 / 评价快照**：Skills.sh 全站榜在 2026-07-31 显示约 107.4K 次安装。
- **采集日期**：2026-07-31
- **安装方式**：按 Skills.sh 详情页显示的 `skills` CLI 命令安装。
- **许可证**：许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验详情页名称、热度和仓库入口；未对外部账户执行动作。
- **风险 / 依赖备注**：任何表单提交、购买、删除、消息发送或账号设置变更都必须由用户明确确认。
