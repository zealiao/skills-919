# 代码评审（code-review）

- **分类**：开发辅助
- **简要用途**：按结构化清单检查变更的正确性、可维护性和潜在风险。
- **核心功能**：
  - 识别实现与需求、测试、边界条件之间的不一致。
  - 组织可执行的评审意见，帮助作者定位到具体问题。
- **适用场景**：Pull Request 审查、重要重构、上线前检查和团队代码规范复核。
