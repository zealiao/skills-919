# skill-creator

- **分类**：开发辅助
- **简要用途**：指导开发者创建、修改、评估和优化可复用的 Agent Skill。
- **核心功能**：
  - 设计触发描述、指令主体和附带资源的目录结构。
  - 为 Skill 编写真实任务的评测提示。
  - 通过评测结果迭代内容与触发准确性。
- **适用场景**：团队封装标准流程、完善已有 Skill、建立 Skill 评测机制。
- **来源平台**：SkillHub 中国
- **来源链接**：https://www.skill-cn.com/skill/8
- **原作者 / 原始仓库**：Anthropic / anthropics/skills
- **原始链接**：https://github.com/anthropics/skills
- **热度 / 评价快照**：SkillHub 中国页面显示热度 74490、Star 163.3k；页面更新于 2026-04-20。
- **采集日期**：2026-07-31
- **安装方式**：`npx skills add https://github.com/anthropics/skills --skill skill-creator`；以原仓库最新说明为准。
- **许可证**：原始许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验平台页面、原始仓库入口和公开安装命令。
- **风险 / 依赖备注**：生成 Skill 时应审查指令、脚本和外部工具权限，避免将不安全流程固化。

## 收录说明

它的价值不在替你完成具体业务，而在于把反复出现的工作沉淀为可维护能力。新建 Skill 前应先明确目标、边界和评测案例。
