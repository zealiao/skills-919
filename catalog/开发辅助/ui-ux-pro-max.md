# UI / UX Pro Max

- **分类**：开发辅助
- **简要用途**：在 AI 编写前端代码时提供成熟的 UI / UX 设计规范，帮助产出更完整、一致的界面。
- **核心功能**：
  - 根据产品类型、页面目标和用户流程提出界面结构建议。
  - 指导布局、层级、色彩、间距和组件状态的一致性。
  - 将设计约束转化为可实现的前端界面要求。
- **适用场景**：网站和 Web 应用的页面设计、前端实现、设计评审和界面重构。
