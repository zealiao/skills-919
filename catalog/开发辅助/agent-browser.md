# agent-browser

- **分类**：开发辅助
- **简要用途**：为 Agent 提供网页导航、表单操作、截图、页面测试和文本提取能力。
- **核心功能**：
  - 打开网页、识别页面元素并执行点击或填写。
  - 提取页面文本和结构化快照。
  - 保存会话状态并辅助调试网页流程。
- **适用场景**：网站回归测试、公开网页研究、表单自动化和页面截图取证。

浏览器自动化很实用，但权限边界也最敏感。默认先使用只读访问和截图验证，任何会提交、购买、删除或发送的动作都必须由用户明确确认。
