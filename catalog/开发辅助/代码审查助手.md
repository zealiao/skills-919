# 代码审查助手

- **分类**：开发辅助
- **简要用途**：阅读变更内容，提示潜在缺陷、测试缺口、可维护性问题和安全风险。
- **核心功能**：
  - 对比提交或 Pull Request 的行为变化。
  - 按影响程度给出可操作的审查意见。
  - 建议补充测试、文档和边界条件。
- **适用场景**：团队 PR 审查、合并前自检、重构后的回归检查。

- **来源链接**：https://www.skill-cn.com/skill/47

- **原始链接**：https://www.skill-cn.com/skill/47
- **热度 / 评价快照**：从平台开发类推荐与热榜入口筛选；具体数值需在详情页补录。
- **采集日期**：2026-07-31
- **安装方式**：在 SkillHub 搜索“代码审查/Code Review”，按详情页配置代码读取权限。
- **许可证**：未核验；不复制原始文件。
- **人工核验**：已核验平台入口；尚未对生产代码运行。
- **风险 / 依赖备注**：不要把密钥、客户代码或私有依赖日志上传给无授权服务；意见不能替代人工批准。

## 收录说明

审查助手应作为第二双眼睛而非合并门禁的唯一依据。它最适合帮助发现遗漏，最终风险判断仍由熟悉系统的人负责。
