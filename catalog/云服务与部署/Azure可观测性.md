# Azure 可观测性（azure-observability）

- **分类**：云服务与部署
- **简要用途**：在 Azure 环境中规划日志、指标、追踪和告警的可观测性基础。
- **核心功能**：
  - 组织监控目标、关键指标、告警条件和排障信息。
  - 提醒在部署后持续验证系统健康状态。
- **适用场景**：Azure 应用运维、服务监控、发布观察和故障排查。
