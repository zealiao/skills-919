# Agent 记忆系统搭建指南

- **分类**：数据分析
- **简要用途**：帮助为 Agent 设计可检索、可更新且受权限控制的长期记忆或知识记录。
- **核心功能**：
  - 区分临时上下文、用户偏好和长期知识。
  - 设计写入、检索、更新和遗忘规则。
  - 提供记忆质量与隐私风险的检查要点。
- **适用场景**：个人知识助手、客户支持 Agent、长期项目协作和研究记录。
