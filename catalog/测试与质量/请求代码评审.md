# 请求代码评审（requesting-code-review）

- **分类**：测试与质量
- **简要用途**：在提交评审前整理改动背景、测试证据和需要重点关注的地方。
- **核心功能**：
  - 生成清晰的 PR 描述、风险说明和验证信息。
  - 帮助把评审范围控制在可理解、可复查的变更单元。
- **适用场景**：Pull Request 发起、关键改动交接、跨团队审查和上线前复核。
- **来源平台**：Skills.sh
- **来源链接**：https://www.skills.sh/obra/superpowers/requesting-code-review
- **原作者 / 原始仓库**：Obra / obra/superpowers
- **原始链接**：https://github.com/obra/superpowers
- **热度 / 评价快照**：Skills.sh 全站榜在 2026-07-31 显示约 185.2K 次安装。
- **采集日期**：2026-07-31
- **安装方式**：`npx skills add https://github.com/obra/superpowers --skill requesting-code-review`
- **许可证**：许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验来源页与仓库入口；未创建或提交任何 Pull Request。
- **风险 / 依赖备注**：自动生成的 PR 描述需核对是否遗漏破坏性变更、迁移或安全影响，不能伪造测试结果。

## 收录说明

它解决“让他人容易评审”的沟通问题，和代码评审 Skill 的检查视角不同。
