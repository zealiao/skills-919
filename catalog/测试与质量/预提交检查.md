# 预提交检查（setup-pre-commit）

- **分类**：测试与质量
- **简要用途**：在代码提交前建立格式化、静态检查和测试等自动质量门槛。
- **核心功能**：
  - 指导设置 pre-commit 钩子和常见检查项。
  - 把低成本问题拦截在提交前，减少 CI 和评审负担。
- **适用场景**：新项目初始化、团队质量规范、代码库治理和本地开发流程。

- **人工核验**：已核验具体详情页和来源仓库；未修改用户的 Git 钩子配置。

## 收录说明
