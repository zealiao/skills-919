# Playwright 命令行（playwright-cli）

- **分类**：测试与质量
- **简要用途**：使用 Playwright CLI 执行浏览器自动化测试与页面操作。
- **核心功能**：
  - 启动浏览器、定位元素、执行交互并获取测试证据。
  - 将关键用户路径变为可重复的测试或调试步骤。
- **适用场景**：端到端测试、回归测试、页面问题复现和测试截图。
