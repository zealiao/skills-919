# 合并冲突处理（resolving-merge-conflicts）

- **分类**：测试与质量
- **简要用途**：以理解两个改动意图为前提，安全处理 Git 合并冲突。
- **核心功能**：
  - 定位冲突来源、比较变更并选择或整合正确实现。
  - 在解决后补充构建、测试和差异复查步骤。
- **适用场景**：分支合并、rebase、多人同时修改同一模块和发布分支维护。
- **来源平台**：Skills.sh
- **来源链接**：https://www.skills.sh/mattpocock/skills/resolving-merge-conflicts
- **原作者 / 原始仓库**：Matt Pocock / mattpocock/skills
- **原始链接**：https://github.com/mattpocock/skills
- **热度 / 评价快照**：Skills.sh 全站榜在 2026-07-31 显示约 195.4K 次安装。
- **采集日期**：2026-07-31
- **安装方式**：`npx skills add https://github.com/mattpocock/skills --skill resolving-merge-conflicts`
- **许可证**：许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验榜单条目和仓库入口；未解决任何用户仓库冲突。
- **风险 / 依赖备注**：不要只为消除冲突标记而删除一方改动；涉及业务逻辑的冲突需由相关作者确认。

## 收录说明

冲突解决的核心是保留正确意图，不是机械地选择“当前”或“传入”版本。
