# Web 应用测试（webapp-testing）

- **分类**：测试与质量
- **简要用途**：为 Web 应用建立单元、集成和端到端测试的组合策略。
- **核心功能**：
  - 选择合适层级验证组件、业务逻辑和用户路径。
  - 指导测试数据、可重复性和覆盖重点的安排。
- **适用场景**：React/Web 项目测试体系、关键路径回归和前端功能发布前检查。
