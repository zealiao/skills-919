# 界面图转代码（image-to-code）

- **分类**：产品设计与前端
- **简要用途**：根据界面截图或设计图辅助生成可继续编辑的前端实现。
- **核心功能**：
  - 识别页面结构、组件、样式层级和布局关系。
  - 将视觉参考转成 HTML/CSS 或框架代码的初稿。
- **适用场景**：原型实现、历史页面重建、设计交接和组件拆分讨论。
