# PPT SVG 生成器

- **分类**：文件与图像处理
- **简要用途**：将 Markdown 文稿拆解并生成可导入 PowerPoint、可转为形状再编辑的 SVG 幻灯片页面。
- **核心功能**：
  - 分析文稿并输出结构化的页面清单。
  - 提供预设、自定义和智能推荐三类视觉风格。
  - 批量生成 PPT 兼容 SVG，并可导出 PDF 或 PPTX。
- **适用场景**：方案汇报、知识分享、培训课件、产品演示和从文稿快速制作 PPT。
