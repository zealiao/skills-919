# 网页应用测试

- **分类**：网页与信息检索
- **简要用途**：把用户路径转成可重复的网页测试步骤，并记录页面状态、截图和失败线索。
- **核心功能**：
  - 规划登录、导航、表单和结果校验路径。
  - 捕获页面文本、元素状态和截图证据。
  - 生成可交给开发人员复现的问题描述。
- **适用场景**：发布前冒烟测试、回归测试、表单流程验证和 UI 缺陷复现。
- **来源平台**：SkillHub 中国
- **来源链接**：https://www.skill-cn.com/skill/12
- **原作者 / 原始仓库**：Vercel Labs / vercel-labs/agent-browser
- **原始链接**：https://github.com/vercel-labs/agent-browser
- **热度 / 评价快照**：关联页面明确列举网页测试、表单填写、截图和数据提取场景；页面数据见来源页。
- **采集日期**：2026-07-31
- **安装方式**：根据来源 Skill 的 CLI 和浏览器环境说明配置；先在测试环境执行。
- **许可证**：原始许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验来源页面；未对第三方生产站点开展测试。
- **风险 / 依赖备注**：仅测试自己拥有或获授权的系统；测试账号、令牌和截图不得提交到公开仓库。

## 收录说明

网页测试条目适合把模糊的“点一遍看看”变成可复现流程。生产环境测试应防止创建真实订单、删除数据或触发通知。
