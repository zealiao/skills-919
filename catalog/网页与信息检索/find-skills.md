# find-skills

- **分类**：网页与信息检索
- **简要用途**：根据当前任务自动寻找、安装或更新更匹配的 Agent Skill。
- **核心功能**：
  - 将任务描述转成可搜索的能力需求。
  - 推荐候选 Skill 并说明适配原因。
  - 协助执行安装和更新的后续步骤。
- **适用场景**：不知道该用什么 Skill、为团队补充工具链、整理 Skill 生态资源。
- **来源平台**：SkillHub 中国
- **来源链接**：https://www.skill-cn.com/practice/240
- **原作者 / 原始仓库**：平台页面关联作者待复核
- **原始链接**：https://www.skill-cn.com/practice/240
- **热度 / 评价快照**：公开实践页称其为用于搜索和安装其他技能的“元 Skill”；具体安装源需详情页确认。
- **采集日期**：2026-07-31
- **安装方式**：打开来源页，跟随关联 Skill 或原始仓库的当前安装指引。
- **许可证**：未核验；不复制原始文件。
- **人工核验**：已核验公开实践页；未自动安装任何第三方 Skill。
- **风险 / 依赖备注**：自动安装可能引入不受信任脚本；安装前需审查来源、许可证、依赖和网络权限。

## 收录说明

它非常适合面对不断变化的 Skill 生态，但推荐结果只是一份候选清单。将新 Skill 引入工作区前，应像引入依赖一样进行安全和许可证审查。
