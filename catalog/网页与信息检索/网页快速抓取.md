# 网页快速抓取（just-scrape）

- **分类**：网页与信息检索
- **简要用途**：为需要从公开网页提取内容的 Agent 提供轻量抓取流程。
- **核心功能**：
  - 将任务目标转换为页面访问、正文提取和结果整理步骤。
  - 支持把抓取结果交给后续分析或研究流程。
- **适用场景**：公开网页资料收集、竞品信息整理和研究前的数据准备。
- **来源平台**：Skills.sh
- **来源链接**：https://www.skills.sh/scrapegraphai/just-scrape/just-scrape
- **原作者 / 原始仓库**：ScrapeGraphAI / scrapegraphai/just-scrape
- **原始链接**：https://github.com/scrapegraphai/just-scrape
- **热度 / 评价快照**：Skills.sh 全站榜在 2026-07-31 显示约 244.9K 次安装。
- **采集日期**：2026-07-31
- **安装方式**：按 Skills.sh 详情页的 CLI 指引安装和配置。
- **许可证**：许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验具体榜单条目和原始仓库入口；未对第三方网站执行抓取。
- **风险 / 依赖备注**：不得绕过验证码、登录、付费墙或反爬措施；请求频率和使用范围应取得授权。
