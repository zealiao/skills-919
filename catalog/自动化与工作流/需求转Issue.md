# 需求转 Issue（to-issues）

- **分类**：自动化与工作流
- **简要用途**：把已澄清的需求或计划拆成可跟踪的工程 Issue。
- **核心功能**：
  - 定义任务标题、范围、验收条件、依赖和优先级提示。
  - 帮助把大需求拆成可独立交付和复核的工作项。
- **适用场景**：项目排期、迭代计划、工程看板和需求拆解。
- **来源平台**：Skills.sh
- **来源链接**：https://www.skills.sh/mattpocock/skills/to-issues
- **原作者 / 原始仓库**：Matt Pocock / mattpocock/skills
- **原始链接**：https://github.com/mattpocock/skills
- **热度 / 评价快照**：Skills.sh 全站榜在 2026-07-31 显示约 347.9K 次安装。
- **采集日期**：2026-07-31
- **安装方式**：`npx skills add https://github.com/mattpocock/skills --skill to-issues`
- **许可证**：许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验具体详情页和仓库入口；未向任何项目管理系统创建 Issue。
- **风险 / 依赖备注**：创建任务会通知协作者并影响排期，批量写入前需确认项目、负责人和权限。

## 收录说明

需求拆解能提高可执行性，但每项任务的业务价值、优先级和负责人仍需人工确认。
