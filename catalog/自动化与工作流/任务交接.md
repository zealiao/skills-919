# 任务交接（handoff）

- **分类**：自动化与工作流
- **简要用途**：在人员、会话或 Agent 之间交接任务时保留目标、上下文、状态和下一步。
- **核心功能**：
  - 提炼已完成事项、未决问题、风险和关键文件。
  - 形成可让接手者快速继续工作的交接摘要。
- **适用场景**：班次交接、项目换人、Agent 会话续作和跨团队协作。
- **来源平台**：Skills.sh

- **原作者 / 原始仓库**：Matt Pocock / mattpocock/skills

- **采集日期**：2026-07-31
- **安装方式**：`npx skills add https://github.com/mattpocock/skills --skill handoff`
- **许可证**：许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验榜单具体条目和仓库入口；未传递用户的敏感项目资料。
- **风险 / 依赖备注**：交接内容须避免泄露密钥、客户数据和内部机密；接手者应验证状态而不盲信摘要。
