# 产品需求文档（to-prd）

- **分类**：自动化与工作流
- **简要用途**：将想法和讨论整理为可评审的产品需求文档（PRD）。
- **核心功能**：
  - 明确问题、用户、目标、范围、验收和非目标。
  - 暴露依赖、风险和仍需决策的需求空白。
- **适用场景**：新功能立项、产品评审、需求澄清和跨团队对齐。
- **来源平台**：Skills.sh

- **采集日期**：2026-07-31
- **安装方式**：`npx skills add https://github.com/mattpocock/skills --skill to-prd`
- **许可证**：许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验具体条目和来源仓库；未将草稿当作自动批准的需求。
- **风险 / 依赖备注**：PRD 必须经产品、技术、运营等相关负责人评审，尤其要明确隐私、合规和上线边界。
