# Git 安全护栏（git-guardrails-claude-code）

- **分类**：自动化与工作流
- **简要用途**：为 AI 辅助 Git 操作设置更安全的检查与提交边界。
- **核心功能**：
  - 在分支、暂存、提交和同步前提醒检查工作区状态。
  - 降低误提交密钥、覆盖他人改动或在错误分支操作的风险。
- **适用场景**：多人协作仓库、AI 编程助手使用、代码提交前检查和分支管理。
- **来源平台**：Skills.sh

- **人工核验**：已核验榜单条目和原始仓库入口；未执行任何 Git 写入操作。
- **风险 / 依赖备注**：护栏不能代替备份、代码审查和访问控制；仍应避免强制推送或无确认的破坏性命令。
