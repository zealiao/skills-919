# 完成开发分支（finishing-a-development-branch）

- **分类**：自动化与工作流
- **简要用途**：在功能完成后组织测试、审查、合并准备和收尾检查。
- **核心功能**：
  - 检查实现、测试、文档和变更范围是否满足合并条件。
  - 指导如何整理分支并向评审者说明改动。
- **适用场景**：Pull Request 提交前、功能验收、发布候选和分支收尾。
- **来源平台**：Skills.sh
- **来源链接**：https://www.skills.sh/obra/superpowers/finishing-a-development-branch
- **原作者 / 原始仓库**：Obra / obra/superpowers
- **原始链接**：https://github.com/obra/superpowers
- **热度 / 评价快照**：Skills.sh 全站榜在 2026-07-31 显示约 148.1K 次安装。
- **采集日期**：2026-07-31
- **安装方式**：`npx skills add https://github.com/obra/superpowers --skill finishing-a-development-branch`
- **许可证**：许可证待在原仓库逐项确认；本仓库不复制原始文件。
- **人工核验**：已核验详情页与仓库入口；未合并或删除任何真实分支。
- **风险 / 依赖备注**：只有有合并权限的人可批准或合并；不得因为检查清单完整就跳过 CI 与人工评审。
