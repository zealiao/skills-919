# skills-919｜可调用功能 Skill 中文目录

这是一个面向智能体实际调用的 Skill 目录。首批精选 50 个条目，重点收录能直接完成具体工作的能力：网页检索和操作、飞书协作、文档与文件处理、数据处理、内容与沟通。

> 本仓库只保存原创中文说明与**直达具体 Skill 详情页**的来源链接，不镜像第三方 Skill 文件。热度、下载量和评分均为采集当日快照；它们仅辅助筛选，不代表实时排名或效果担保。许可证未单独核验的条目均不复制原始文件，详见 [LICENSES.md](LICENSES.md)。

## 如何使用

1. 从分类或表格进入条目，先阅读用途、权限和风险。
2. 打开“来源链接”确认最新安装方式、许可证和平台说明。
3. 遇到发消息、发邮件、审批、删除、覆盖写入等外部影响操作，先预览并取得人工确认。
4. 新增或更新条目时，遵循 [贡献指南](CONTRIBUTING.md) 和 [条目模板](docs/skill-template.md)。
