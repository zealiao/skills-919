# skills-919｜热门实用 Skill 中文目录

一个面向日常办公、开发、内容创作和信息处理的 Skill 发现目录。现收录 100 个候选条目，优先看业务场景实用性，并参考来源平台的公开安装量、热度、评价和更新情况。

> 本仓库默认只保存原创中文说明和**可直达具体 Skill 详情页**的来源链接，不镜像第三方 Skill 文件。分类、首页、合集和实践页只能作为发现线索，不能作为单个 Skill 的来源。具体规则见 [LICENSES.md](LICENSES.md)。热度/评价均为采集日快照，不代表实时排名或效果担保。

## 如何使用

1. 按分类打开条目，先阅读用途、风险和适用场景。
2. 通过“来源链接”打开平台详情，确认最新说明、更新状态和许可证。
3. 仅在原作者许可、依赖安全且权限范围合适时安装。
4. 需要新增或更新条目时，遵循 [贡献指南](CONTRIBUTING.md) 并使用 [条目模板](docs/skill-template.md)。

## 来源与筛选

候选来自 [腾讯 SkillHub](https://skillhub.cn/)、[虾评 Skill](https://xiaping.coze.com/)、[SkillHub 中国](https://www.skill-cn.com/)、[SkillsMP](https://skillsmp.com/)、[Skills.sh](https://www.skills.sh/) 和 [Skill4Agent](https://www.skill4agent.com/zh/)。本批新增条目以 Skills.sh 的公开安装量为主要热度信号，并以 SkillsMP、Skill4Agent 的公开数据作交叉参考；选择时仍优先考虑通用场景、来源可追溯性、维护迹象和安全/许可证风险。详细标准见 [筛选标准](docs/selection-rubric.md)。

## 本地检查

无需安装依赖，执行：

```bash
npm run check
```

它会验证 100 个条目的数量、必填字段、直达详情页链接格式，以及“未核验许可证不复制原始文件”的目录规则。
