# 收录筛选标准

## 候选评估

按以下顺序判断是否收录：

1. **业务价值**：是否能解决办公、开发、内容、数据、检索或文件处理中的常见问题。
2. **平台信号**：参考公开下载、热度、评分、推荐、更新日期或实践反馈；这些信号只用于排序，不等同于安全保证。
3. **可追溯性**：来源链接必须直达单个 Skill 的平台详情页；首页、分类、合集和实践页只可用于发现候选，不能作为收录链接。
4. **维护和安全**：优先说明清楚、依赖透明、近期仍可访问的条目；高权限、自动发布、金融交易、医疗法律建议等风险场景不作为首期重点。
5. **版权**：许可证不明确时仅做链接索引，绝不复制原始内容。

## 去重规则

- 同一原始 Skill 出现在多个平台时，建立一个主条目，在“来源链接”中保留发现平台，避免重复收录。
- 仅名称相似但输入、输出或使用场景不同的 Skill 可分别收录，说明差异。
- 合集只作为发现入口；其中许可清晰、说明完整的具体 Skill 应在后续单独建页。

## 月度复查

每月任选一个维护者复查所有条目的来源链接、更新迹象和风险备注。失效、侵权投诉、安全问题或与目录范围不符的条目移入 `archive/`，保留日期和处置原因。
